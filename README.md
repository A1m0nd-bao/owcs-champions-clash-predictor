# OWCS Champions Clash 2026 Predictor

一个静态 OWCS 2026 Champions Clash 预测器，用于从初始种子开始点击胜者，自动推进胜者组、败者组和总决赛，并展示冠亚季军。

数据与赛制基准：

- Liquipedia: Overwatch Champions Series 2026 Champions Clash
- 481651.xyz: OWCS 数据可视化

直接打开 `index.html` 即可本地使用。

## Assets

队标文件存放在 `assets/logos/`，来源为 Liquipedia Overwatch 队伍页 infobox 实际引用的文件。队名、队标和商标归各自俱乐部或权利方所有；本项目仅用于非商业赛事预测展示。页面不会热链接 Liquipedia 图片资源。

如果某支队伍的 Overwatch 队伍页没有配置队标，例如当前的 Virtus.pro，则页面使用文字徽章兜底，不借用其他项目页面的 logo。
